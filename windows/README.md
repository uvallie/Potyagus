# Потягусь для Windows (прототип)

Та сама `web/overlay.html`, що й у Mac-версії, **без жодної правки**, тільки замість Swift + WKWebView
тут C#/.NET 8 + WebView2. Mac-застосунок (`src/main.swift`, `build.sh`, `bin/potyagus`) цей код не чіпає.

## Що вміє

Повторює Mac-версію крок за кроком:

- живе в треї (іконка гуся біля годинника) і сам додає себе в автозапуск;
- приходить за тим самим розкладом: `minute` + `intervalMinutes` (за замовчуванням щогодини о :05);
- на **кожному** моніторі відкривається повноекранне вікно без рамки поверх усього, включно з панеллю задач;
  звук грає лише там, де курсор; перший клік на будь-якому екрані закриває всі, в історію пишеться один раз;
- старт по кліку (або пробіл / Enter) → 3-2-1 → таймер → «Готово»; «Ще 5 хв» повертає гуся за 5 хвилин;
  «Не турбувати» працює так само; якщо гуся ігнорують, він іде сам через `seconds + 240` с;
- Alt+F4 його не закриває, тільки кнопки на екрані;
- меню в треї: скільки розім'ялась сьогодні, коли наступний вихід, «Потягнутись зараз», пауза,
  каталог вправ із галочками, частота, звук, «Приховати іконку», «Вимкнути автозапуск і вийти», «Вийти»;
- мовчить, коли екран заблоковано, поза робочими годинами, у вихідні (`weekdaysOnly`), на паузі,
  під час дзвінка і коли спереду застосунок із `blockApps`.

## Зібрати

Потрібні Windows 10/11 і .NET 8 SDK (`winget install Microsoft.DotNet.SDK.8`).

```powershell
git clone https://github.com/uvallie/Potyagus.git
cd Potyagus
.\windows\build.ps1
```

Результат — папка `windows\dist\Potyagus\` (`Potyagus.exe`, `web\`, `exercises.json`) і поруч zip.
Збірка самодостатня: .NET ставити не треба. Потрібен лише Microsoft Edge WebView2 Runtime, який уже є
в Windows 11 і в оновленій Windows 10; якщо його немає, застосунок скаже, звідки взяти.

Готовий zip також збирає GitHub Actions (`.github/workflows/windows.yml`) на кожен пуш у `windows/`, `web/`
чи `data/`: вкладка Actions → останній запуск «Windows build» → артефакт `Potyagus-windows-x64`.

## Запустити

```powershell
.\windows\dist\Potyagus\Potyagus.exe            # оселитись у треї (і в автозапуску)
.\windows\dist\Potyagus\Potyagus.exe --now      # показати гуся просто зараз і вийти
.\windows\dist\Potyagus\Potyagus.exe --check    # чи вийшов би зараз, не чіпаючи екран
.\windows\dist\Potyagus\Potyagus.exe --devices  # хто тримає мікрофон і хто грає звук
```

Повторний запуск, коли гусь уже в треї, повертає приховану іконку. SmartScreen при першому запуску
може попередити про невідомого видавця («Докладніше» → «Однаково запустити»), бо exe не підписаний.

## Налаштування й дані

`%APPDATA%\Potyagus\` — ті самі файли й ключі, що на Mac: `config.json`, `history.jsonl`, `paused-until`,
плюс `agent.log`. Різниця одна: у `blockApps` на Windows пишуться **імена процесів**
(як у Диспетчері завдань → «Подробиці», без `.exe`), а не bundle ID. За замовчуванням:
`Zoom`, `ms-teams`, `Teams`, `Discord`, `CiscoCollabHost`, `webexmta`.

## Як він бачить дзвінок

Та сама логіка, що на Mac: мікрофон зайнятий **і** щось грає звук → дзвінок; лише мікрофон → голосовий набір.
Через `confirmCallSeconds` перевіряє ще раз.

- мікрофон — з того самого реєстру, з якого Windows малює свій індикатор «мікрофон використовується»
  (`CapabilityAccessManager\ConsentStore\microphone`), без жодних дозволів;
- звук — активні аудіосесії WASAPI на будь-якому вихідному пристрої.

## Як це влаштовано

| Файл | Роль |
|---|---|
| `src/Program.cs` | вхід, один екземпляр, `--now` / `--check` / `--devices` |
| `src/Agent.cs` | трей, розклад, показ і закриття оверлею, історія, автозапуск (`HKCU\…\Run`) |
| `src/OverlayForm.cs` | вікно на моніторі + WebView2 і міст до сторінки |
| `src/Gate.cs` | причини не виходити: пауза, блокування, години, дзвінок, блоклист |
| `src/Store.cs` | `config.json`, `exercises.json`, `history.jsonl`, `paused-until` |

Сторінка відкривається з віртуального хоста `https://potyagus.local/overlay.html` (папка `web\` поруч з exe),
а не через `file://`, щоб хромакей на canvas міг читати пікселі відео. Перед завантаженням сторінки
підкладається маленький шим `window.webkit.messageHandlers.rozimnys` → `chrome.webview.postMessage`,
тож `overlay.html` думає, що вона в WKWebView. Ще шим ставить шрифт Segoe UI, бо SF Pro на Windows немає.

## Чого поки немає порівняно з Mac

- плавної появи й зникнення вікна (на Mac 0,4 с); тут гусь просто з'являється на зеленому тлі;
- CLI-обгортки на кшталт `bin/potyagus` (`pause`, `stats`, `status`): поки лише прапорці exe;
- інсталятора й підпису: це zip, який розпаковуєш куди завгодно і запускаєш.
