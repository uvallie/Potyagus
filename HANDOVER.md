## Архітектура за хвилину

| Файл | Роль |
|---|---|
| `src/main.swift` | вікно на рівні скрінсейвера на кожному екрані, WKWebView, launchd-логіка, детекція дзвінків (CoreAudio), історія |
| `web/overlay.html` | **єдине джерело правди для інтерфейсу**: стани idle → countdown → active, два SVG-риги гуся, 24 CSS-пози, звук |
| `data/exercises.json` | `exercises` (17 активних), `retired` (7 відкладених), `taunts`, `done_lines` |
| `bin/potyagus` | CLI: install/now/check/devices/pause/resume/status/stats/config/build/uninstall |
| `build.sh` | swiftc → `Potyagus.app`, копіює overlay, json, іконку; не в git |
| `art/goose-rig.html` | пісочниця ригу: всі 24 пози поруч з оригіналом, `window.freeze(t)` |
| `art/candidates/` | згенеровані варіанти дизайну; канон — `u2.svg` |
| `art/icon/` | іконка (SVG → 1024 PNG → .icns) |
| `v2/` | відео-версія, вимкнена (див. нижче) |

Міст JS → Swift: `window.webkit.messageHandlers.rozimnys.postMessage({action})`,
дії `done | snooze | skip`. Swift → JS: `window.rozimnysInit(payload)` після завантаження.
Ідентифікатор обробника лишився `rozimnys` — це внутрішня назва, не чіпати без потреби.

## Ключові рішення і чому

1. **Старт лише по кліку → 3-2-1 → таймер.** Без кліку таймер не йде, «Готово» з'являється
   тільки після таймера. Інакше вправу можна «просидіти». Її вимога.
2. **SVG-риг, а не відео (v1).** Риг дає рух за нуль кредитів, важить кілобайти, не пливе між
   вправами. Відео гарніше, але це v2 — її рішення.
3. **Два ракурси гуся.** Профіль для рухів у сагітальній площині (тягнення, нахили, кіт-корова),
   анфас для симетричних (присід, зірочка, нахили й півкола головою, груди). Таблиця `VIEW`
   у скрипті overlay. Півкола головою — **тільки анфас**, у профіль читаються як кивання.
4. **Крила — буквально руки.** Кіт-корова: крило впирається в підлогу. Ікри: крило в стіну.
   Стегно: крило тримає підняту стопу. Це прямий фідбек Аліни.
5. **Стиль**: плаский, два кольори, без обводок, без міміки — крапка ока; характер несе поза.
   Референс — гуси в дусі Untitled Goose Game (емденська порода). Не «діснеївські».
6. **Дзвінки**: мікрофон + динаміки одночасно = дзвінок; лише мікрофон = диктування (не блокувати).
   Перепитує через 8 с. Під час дзвінка чекає до 45 хв по 5 хв, не втрачає годину.
7. **Мультимонітор**: повний інтерфейс на кожному екрані; звук лише там, де курсор;
   перший клік виграє, в історію один запис.
8. **Лужок і великий напис «Потягусь»** — її запит; горизонт на 66vh, гусь стоїть на ньому.
9. **Звук — синтез у Web Audio** («га-гак» при появі через 1 с, потрійне на завершення).
   Нативний NSSound прибрано. **Аліна ще не підтвердила, як це звучить** — перевірити з нею.

## Технічні граблі, на які вже наступали

- `NSWindow(contentRect: screen.frame, …, screen: screen)` зміщує вікно двічі — передавати
  або глобальний rect, або `screen:`, не обоє.
- `NSScreen.main` для фонового агента без key window — випадковий; активний екран краще
  брати за курсором (`NSEvent.mouseLocation`).
- Пряме виконання бінарника з терміналу/скрипта повертає одразу (без GUI-сесії). Тестувати
  через `launchctl kickstart -p gui/$UID/com.alina.potyagus` або `potyagus now`.
- SVG-елементам не присвоюється `className` — тільки `setAttribute("class")`.
- У `transform-box:view-box` `transform-origin` задається в координатах viewBox — так і
  зроблено для всіх суглобів ригу. Додатний кут у SVG = за годинниковою (ліва лапа для
  «коліна назовні» потребує плюса).
- В одному документі два риги → частини звертаються **класами** `.p-neck`, `.p-wing`…,
  не id. Пісочниця `art/goose-rig.html` використовує id — при перенесенні CSS робити
  заміну `#name → .p-name` (так робив скрипт-порт; його більше нема, робити вручну).
- Раніше `overlay.html` збирався з шаблону в тимчасовій папці сесії. **Шаблону більше немає —
  правити напряму `web/overlay.html`.** Блок поз між
  `/* ===== CHARACTER POSES ===== */` і `@media (prefers-reduced-motion)`.
- zsh падає з «character not in range» на кирилиці всередині `$(…)` — ставити
  `export LC_ALL=en_US.UTF-8`.
- Скріншоти Browser-панелі масштабують 1470px → 466px і «ховають» відступи й дрібний текст.
  Перевіряти відступи замірами через JS (`getBoundingClientRect`) або на viewport ~960px.
- `qlmanage -t -s 1024 -o . file.svg` растеризує SVG з альфою — достатньо для іконки та
  стартових кадрів відео.

## Що зроблено сьогодні (хронологічно, коротко)

блоб-персонаж → мультимонітор → детекція дзвінків → гусь (Higgsfield → SVG-риг) → 24 пози,
дві камери, коліна → відбір 14 → повернення 3 (очі, стегно, груди) → клік-старт, лужок →
відступи/контраст → відео-пілот (v2) → git, перейменування на Potyagus, іконка →
півкола головою анфас → фікс двох гусей → ґелґотання.

## Відкрите / наступні кроки

1. **Простіша установка** (Аліна питала, рішення не прийняла): GitHub Actions збирає універсальний
   `.app` → Releases; апка при першому запуску сама ставить launchd-агент («перетягнув, відкрив»);
   `install.sh` одним рядком. Без Apple Developer ID Gatekeeper проситиме правий клік → «Відкрити».
   Запитати, чи є Developer акаунт.
2. **Звук** — почути її вердикт; крутити 300/340 Гц, тривалість, гучність 0.22 у `honk()`.
   Альтернатива — згенерувати SFX через Higgsfield.
3. **Кнопка «Готово» до кінця таймера прибрана свідомо** — вона може попросити повернути.
4. **v2 (відео)** — пайплайн доведено, увімкнення: `USE_CLIPS = true`, `cp -R v2/clips web/clips`,
   `./bin/potyagus build`. Решта 14 кліпів × 26 кредитів на Seedance.
5. При підключенні/відключенні монітора під час показу вікна не перераховуються до наступної години.

## Як працює Аліна (для наступної сесії)

Дає фідбек короткими репліками посеред роботи — це нормальний режим, кожну треба підхопити
в тому ж ході. Хоче, щоб незгоду казали коротко і робили по її рішенню. Вправи й пози
оцінює на **зрозумілість руху** — «щоб було зрозуміло, що він робить». Дизайн-референси
надсилає картинками. Кредитів на Higgsfield не шкодує, але просить назвати ціну наперед.
