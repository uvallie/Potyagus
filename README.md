# Potyagus

Щогодини екран заливає лужок, і на ньому стоїть **Потягусь** — нахабний гусь, який зухвало
коментує твою поставу й не дає працювати, поки ти не розімнешся. Він не просто стоїть поруч:
у нього своя поза на кожну вправу, і він робить її разом з тобою — крилами як руками.

Нічого не запускається саме. Гусь чекає, доки ти **встанеш і клацнеш** — тоді йде відлік
3-2-1 і починається вправа. Просидіти таймер у кріслі не вийде: без кліку він не піде.

Нативний macOS-застосунок: вікно на рівні скрінсейвера — перекриває все, включно з меню-баром
і повноекранними додатками.

**Мультимонітор:** повний інтерфейс відкривається на *кожному* екрані, тож він ніколи не
опиняється не на тому моніторі. Звук лунає лише там, де зараз курсор. Натиснути «Готово»
можна на будь-якому екрані — закриються всі, а в історію запишеться один раз.

## Встановити на Mac

Потрібен macOS 13+ і Swift-компілятор з Xcode Command Line Tools
(`xcode-select --install`, якщо його ще немає). Далі:

```bash
git clone https://github.com/uvallie/Potyagus.git ~/Documents/Code/Potyagus
cd ~/Documents/Code/Potyagus
./bin/potyagus install
```

Одна команда збирає `Potyagus.app` і ставить launchd-агент, який будить Потягуся
**щогодини о :00**. Жодних системних дозволів не просить: ні мікрофона, ні запису екрана —
детекція дзвінків читає лише стан аудіопристроїв, а це дозволу не потребує.
Прибрати повністю — `./bin/potyagus uninstall`.

Перевірити просто зараз:

```bash
./bin/potyagus now
```

## Команди

| Команда | Що робить |
|---|---|
| `potyagus install` | зібрати + поставити на автозапуск |
| `potyagus now` | викликати Потягуся негайно |
| `potyagus check` | чи вийшов би зараз — не чіпаючи екран |
| `potyagus devices` | стан мікрофона й динаміків (діагностика дзвінків) |
| `potyagus pause 90` | пауза на 90 хвилин |
| `potyagus resume` | зняти паузу |
| `potyagus status` | статус агента + статистика |
| `potyagus stats` | скільки разів розім'ялась, серія днів, улюблена вправа |
| `potyagus stop` / `start` | вимкнути / увімкнути агента |
| `potyagus config` | відкрити налаштування |
| `potyagus build` | перезібрати після правок |
| `potyagus uninstall` | прибрати з автозапуску |

## Налаштування

`~/Library/Application Support/Potyagus/config.json`

```json
{
  "startHour": 9,
  "endHour": 21,
  "weekdaysOnly": false,
  "goal": 8,
  "blockApps": ["us.zoom.xos", "com.microsoft.teams2", "com.apple.FaceTime"]
}
```

- **startHour / endHour** — вікно, коли Потягусь має право турбувати.
- **weekdaysOnly** — `true`, щоб на вихідних мовчав.
- **goal** — скільки розминок на день вважається нормою (крапки внизу екрана).
- **blockApps** — bundle ID застосунків, під час яких він не вискакує.
  Дізнатись ID активного вікна: `osascript -e 'id of app (path to frontmost application as text)'`
- **skipDuringCalls** — не турбувати під час дзвінка.
- **requireOutputForCall** — вимагати, щоб і динаміки були активні (див. нижче).
- **confirmCallSeconds** — через скільки секунд перепитати, перш ніж повірити, що це дзвінок.
- **callRetryMinutes / callRetryWindowMinutes** — як часто перевіряти знову і скільки максимум чекати.

Потягусь також сам мовчить, якщо екран заблоковано або стоїть пауза.

## Дзвінки

Zoom, Google Meet, Teams, Slack huddle, FaceTime — усі вони тримають мікрофон,
тож саме мікрофон і є сигналом. Це працює й для Meet, який живе у вкладці браузера
і власного bundle ID не має, тож блоклистом його не спіймати.

**Голосовий набір не рахується за дзвінок.** Диктування теж тримає мікрофон, тому
самого мікрофона мало. Розрізнення таке: на дзвінку ти ще й *слухаєш*, тобто
активний і вхід, і вихід; під час диктування працює лише мікрофон. Додатково
програма перепитує через 8 секунд — диктування короткочасне, дзвінок ні.

Побачити, що воно бачить:

```bash
./bin/potyagus devices
```

Дзвінок не з'їдає годину: поки він іде, Потягусь перевіряє кожні 5 хвилин
(до 45 хвилин) і виходить одразу, як ти звільнишся.

Якщо колись не спіймає дзвінок — постав `"requireOutputForCall": false`.
Тоді будь-який зайнятий мікрофон вважатиметься дзвінком, включно з диктуванням.

## Що на екрані

Три стани, один за одним:

1. **Очікування.** Лужок, великий напис «Потягусь», зухвала репліка (випадкова з 25),
   картка з назвою вправи та кнопка **«Встаю — поїхали»**. Клацнути можна й будь-де на
   екрані або натиснути пробіл. Гусь стоїть і чекає разом з тобою.
2. **Відлік 3-2-1.** Великі цифри, звук на кожну — час підвестись і стати рівно.
3. **Вправа.** Гусь стає в позу і робить її з тобою; кільце-таймер відраховує секунди,
   під карткою — кроки. Кнопка «Готово» з'являється **тільки коли таймер добіг** —
   дострокового «готово» нема. Далі конфеті, і вікно саме зникає через ~3 секунди.

У будь-якому стані є **«Ще 5 хв»** (сховається й повернеться) і **«пропустити цю годину»**.
Якщо просто зігнорувати — через `тривалість + 4 хв` піде сам і запише це як `ignored`.
В історію також пишеться, чи був старт (`started`) і скільки реально тривала вправа.

## Вправи

17 вправ — відібрані під те, що ламається саме від довгого сидіння.

**Шия й голова** (від нахилу до екрана): вухо до плеча, півкола головою, підборіддя назад.

**Очі** (від екрана): правило 20-20-20 — гусь витягує шию і дивиться вдалину.

**Спина й груди** (від згорбленої пози): дотягнись до стелі, розкриття грудей — крила
за спину, бічний нахил, прогин назад, нахил вперед до пальців ніг.

**Ноги й кровообіг** (від нерухомості): присідання, марш з високими колінами,
стрибки «зірочка», розтяжка стегон — гусь тримає крилом підняту стопу, просто пройдись.

**Плечі й дихання:** великі кола руками, три глибокі вдихи, струсити все з себе.

Вправа обирається випадково й не повторюється, поки не пройдуть інші чотири.

### Відкладені вправи

Ще сім вправ лежать у `data/exercises.json` у масиві `retired` — кола плечима,
скручування хребта, зап'ястки, ікри біля стіни, кіт-корова, кола стопами, бічні випади.

Їхні анімації нікуди не зникли — усі 24 пози лишаються в `overlay.html`. Щоб повернути
будь-яку, досить перенести її об'єкт з `retired` назад у `exercises` і перезібрати.

## Звідки взявся гусь

Дизайн згенеровано через Higgsfield (Recraft V4.1 у векторному режимі) — у `art/candidates/`
лежать усі варіанти, канонічний це `u2.svg`. Стиль навмисне плаский і безликий:
два кольори, без обводок, замість міміки — одна крапка ока. Характер несе поза, а не морда.

Сам застосунок використовує не згенерований файл, а **риг** — перемальовану версію того ж
гуся, у якій шия, крило й лапи є окремими групами з точками обертання. Згенерований SVG
для цього не годився: тіло, шия й голова в ньому злиті в один контур, а крило, якого немає
окремою фігурою, підняти неможливо.

Пропорції ригу зняті з оригіналу вимірюванням, а не на око. Риг має вісім рухомих частин:
шия, голова, крило, хвіст, дві лапи і дві стопи — плюс корпус, який можна нахиляти,
стискати й підкидати.

### Два ракурси

Гусь намальований двічі: у профіль і анфас. Кожна вправа сама обирає ракурс, у якому
її видно — таблиця `VIEW` на початку скрипта в `overlay.html`. Скручування, присідання,
випади, «зірочка» і нахили голови читаються тільки з фронту; потягування, кіт-корова,
розтяжка ікор і стегон — тільки в профіль.

Фронтальний гусь має два крила й два ока, профільний — одне крило та хвіст.
В обох лапи складаються з двох ланок із колінним суглобом, тож присід і марш
показують справжнє згинання, а не просто поворот прямої палиці.

### Пісочниця

`art/goose-rig.html` — відкривається просто в браузері, показує всі 24 пози з міткою
ракурсу, включно з відкладеними. `window.freeze(0.5)` у консолі зупиняє анімації на піку руху, щоб роздивитись
позу; `window.freeze(0.25)` — на чверті, для рухів, що чергують боки.

## Версія 2: відео замість ригу (відкладено)

У `v2/` лежить готовий, але вимкнений шлях, де гуся анімує не SVG-риг, а відеокліпи,
згенеровані з референсного арту. Пілот пройшов повністю:

- **Нейтральні кадри** (`v2/neutral/`) — гусь стоїть у профіль і в три чверті на зеленому
  `#7DB262`, що збігається з травою лужка. Це стартовий і кінцевий кадр кожного кліпу.
- **Замкнена петля.** Обидві моделі приймають `start_image` і `end_image`; один і той самий
  нейтральний кадр на початок і кінець змушує рух повернутись у стартову позу. Перевірено
  числами: різниця першого й останнього кадру 0.8–1.5 з 255.
- **Три кліпи** (`v2/clips/`): `idle.mp4` — гусь чекає й повертає голову в камеру;
  `reach.mp4` — дотягнись до стелі, профіль; `chest.mp4` — розкриття грудей, анфас.
  Seedance 2.5, 720p, 6 с, по 26 кредитів.
- **Порівняння моделей** (`v2/video-tests/`): MiniMax удвічі дешевший, але домальовує пір'я
  на розкритих крилах; Seedance тримає пласкі форми чистіше і дає файли втричі менші.

Інтеграція вже в `overlay.html`: `<video>` у слоті гуся з м'якою маскою і розмитою зеленою
галявиною позаду, кліп підставляється для пози, у якої є файл, риг лишається запасним.
Вимкнено одним прапорцем — `USE_CLIPS = false` на початку скрипта.

Щоб увімкнути: `USE_CLIPS = true`, скопіювати `v2/clips` у `web/clips`, `./bin/potyagus build`.
Решта 15 вправ — по 26 кредитів на Seedance, ~400 разом, плюс перегенерації.

## Структура

```
Potyagus/
├── bin/potyagus        CLI
├── build.sh            збірка .app
├── src/main.swift      нативна оболонка (вікно, launchd, історія, детекція дзвінків)
├── web/overlay.html    Потягусь + інтерфейс (SVG-риг, стани, таймер)
├── data/exercises.json вправи, репліки, фінальні фрази, відкладені вправи
├── art/goose-rig.html  пісочниця: усі 24 пози поруч із оригіналом
├── art/candidates/     згенеровані варіанти дизайну (канон — u2.svg)
├── v2/                 відео-версія: кліпи, нейтральні кадри, проби (вимкнено)
└── Potyagus.app       зібраний застосунок (не в git — збирається install'ом)
```

Історія пишеться в `~/Library/Application Support/Potyagus/history.jsonl` — по рядку на подію.

## Як додати свою вправу

Дописати об'єкт у `data/exercises.json`, додати CSS-позу з таким же `pose` у `web/overlay.html`
(секція `CHARACTER POSES`), тоді `./bin/potyagus build`.

## Змінити зовнішній вигляд

`web/overlay.html` самодостатній — його можна відкрити просто в браузері,
щоб покрутити дизайн без перезбірки. Потім `./bin/potyagus build`.
