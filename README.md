# Potyagus

Щогодини екран заливає лужок, і на ньому стоїть **Потягусь** — нахабний гусь, приходить нагадати про шию, спину й ноги. Дедлайни почекають пів хвилини. 
Він не просто стоїть поруч, він робить її разом з тобою.

Таймер запускається лише після кліку, тому тихенько пересидіти розминку за ноутбуком не вийде.

Потягусь живе в меню-барі macOS, знає 17 вправ і веде просту статистику: скільки разів ти розімʼялась сьогодні, серію активних днів і найчастішу вправу.

## Як це працює

Щогодини Потягусь:

1. перевіряє, чи ти не на дзвінку і чи екран не заблокований;
2. зʼявляється поверх усіх вікон на кожному моніторі;
3. чекає, поки ти натиснеш «Встаю - поїхали»;
4. запускає відлік 3-2-1 і показує вправу;
5. записує результат у локальну історію.

Якщо момент зовсім невдалий, нагадування можна відкласти на 5 хвилин або пропустити на цю годину.

Під час дзвінків Потягусь мовчить. Він перевіряє стан мікрофона й аудіовиходу, не записує звук і не просить доступу до мікрофона чи екрана. Коли дзвінок закінчиться, гусь спробує повернутися.

**Мультимонітор:** повний інтерфейс відкривається на *кожному* екрані, тож він ніколи не
опиняється не на тому моніторі. Звук лунає лише там, де зараз курсор. Натиснути «Готово»
можна на будь-якому екрані — закриються всі, а в історію запишеться один раз.

## Встановити на Mac

### Просто: DMG

Скачай **[Potyagus-0.2.dmg](https://github.com/uvallie/Potyagus/releases/latest)**, перетягни
`Potyagus.app` у «Програми» і відкрий. Перший раз — правий клік → «Відкрити», бо застосунок
підписаний без Apple Developer ID. Далі він сам:

- оселяється в меню-барі (іконка гуся) і ставить себе на автозапуск при вході;
- приходить **щогодини о :05** (о :00 зазвичай стартують дзвінки, а до :05 мікрофон уже зайнятий і перевірка дзвінка це бачить; хвилина міняється в `config.json` → `minute`);
- у меню: скільки разів розім'ялась сьогодні, «Потягнутись зараз», пауза на 30 хв / 1 год /
  2 год / до кінця дня, «Вийти» і «Вимкнути автозапуск».

Жодних системних дозволів не просить: ні мікрофона, ні запису екрана — детекція дзвінків
читає лише стан аудіопристроїв.

### З кастомізацією: з коду

Якщо хочеться своїх вправ, реплік, годин чи іншого гуся — збирай з репозиторію, і все
налаштовується через JSON (див. [Налаштування](#налаштування) і [Вправи](#вправи)).
Потрібен macOS 13+ і Swift з Xcode Command Line Tools (`xcode-select --install`):

```bash
git clone https://github.com/uvallie/Potyagus.git ~/Documents/Code/Potyagus
cd ~/Documents/Code/Potyagus
./bin/potyagus install
```

Одна команда збирає `Potyagus.app` і запускає той самий агент у меню-барі.
Після правок у `data/exercises.json` чи `web/overlay.html` — `./bin/potyagus install` ще раз.
Свій DMG — `./build-dmg.sh`. Прибрати повністю — `./bin/potyagus uninstall`.

Перевірити просто зараз:

```bash
./bin/potyagus now
```

## Команди

| Команда | Що робить |
|---|---|
| `potyagus install` | зібрати + поставити на автозапуск (агент у меню-барі) |
| `potyagus now` | викликати Потягуся негайно |
| `potyagus check` | чи вийшов би зараз — не чіпаючи екран |
| `potyagus devices` | стан мікрофона й динаміків (діагностика дзвінків) |
| `potyagus pause 90` | пауза на 90 хвилин |
| `potyagus resume` | зняти паузу |
| `potyagus status` | статус агента + статистика |
| `potyagus stats` | скільки разів розім'ялась, серія днів, улюблена вправа |
| `potyagus stop` / `start` | вимкнути / увімкнути агента |
| `potyagus config` | відкрити налаштування |
| `potyagus build` | перезібрати після правок |
| `potyagus uninstall` | прибрати з автозапуску |

## Налаштування

`~/Library/Application Support/Potyagus/config.json`

```json
{
  "startHour": 9,
  "endHour": 21,
  "minute": 5,
  "weekdaysOnly": false,
  "goal": 8,
  "blockApps": ["us.zoom.xos", "com.microsoft.teams2", "com.apple.FaceTime"]
}
```

- **startHour / endHour** — вікно, коли Потягусь має право турбувати.
- **weekdaysOnly** — `true`, щоб на вихідних мовчав.
- **goal** — скільки розминок на день вважається нормою (крапки внизу екрана).
- **blockApps** — bundle ID застосунків, під час яких він не вискакує.
  Дізнатись ID активного вікна: `osascript -e 'id of app (path to frontmost application as text)'`
- **skipDuringCalls** — не турбувати під час дзвінка.
- **requireOutputForCall** — вимагати, щоб і динаміки були активні (див. нижче).
- **confirmCallSeconds** — через скільки секунд перепитати, перш ніж повірити, що це дзвінок.
- **callRetryMinutes / callRetryWindowMinutes** — як часто перевіряти знову і скільки максимум чекати.

Потягусь також сам мовчить, якщо екран заблоковано або стоїть пауза.

## Дзвінки

Zoom, Google Meet, Teams, Slack huddle, FaceTime — усі вони тримають мікрофон,
тож саме мікрофон і є сигналом. Це працює й для Meet, який живе у вкладці браузера
і власного bundle ID не має, тож блоклистом його не спіймати.

**Голосовий набір не рахується за дзвінок.** Диктування теж тримає мікрофон, тому
самого мікрофона мало. Розрізнення таке: на дзвінку ти ще й *слухаєш*, тобто
активний і вхід, і вихід; під час диктування працює лише мікрофон. Додатково
програма перепитує через 8 секунд — диктування короткочасне, дзвінок ні.

Побачити, що воно бачить:

```bash
./bin/potyagus devices
```

Дзвінок не з'їдає годину: поки він іде, Потягусь перевіряє кожні 5 хвилин
(до 45 хвилин) і виходить одразу, як ти звільнишся.

Якщо колись не спіймає дзвінок — постав `"requireOutputForCall": false`.
Тоді будь-який зайнятий мікрофон вважатиметься дзвінком, включно з диктуванням.

## Що він пропонує робити

У наборі 17 коротких вправ для того, що найбільше страждає від довгого сидіння:

- шия й голова;
- очі;
- спина й груди;
- ноги й кровообіг;
- плечі й дихання.

Вправи обираються випадково. Одна й та сама не повторюється, доки не пройдуть щонайменше чотири інші.

## Дані й приватність

Потягусь працює локально. Налаштування та історія зберігаються в:

```
~/Library/Application Support/Potyagus/
```

Застосунок не записує мікрофон, екран або дзвінки. Для визначення дзвінка він читає тільки системний стан аудіопристроїв.

## Для тих, хто хоче залізти під капот

Основна логіка застосунку живе у `src/main.swift`, інтерфейс - у `web/overlay.html`, вправи й репліки - у `data/exercises.json`.

Деталі архітектури, анімацій і відеопайплайну описані в `HANDOVER.md` та `v2/README.md`.
