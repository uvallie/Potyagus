# Windows-інсталятор

Тут лежить усе, що пакує Windows-шелл (`windows/`) у `Potyagus-<версія>-Setup.exe`:

| Файл | Що робить |
|---|---|
| `potyagus.iss` | скрипт Inno Setup (іконка з `windows/potyagus.ico`): ставить у `%LOCALAPPDATA%\Programs\Potyagus` без прав адміна, ярлик у «Пуску», автозапуск (`HKCU\…\Run`, значення `Potyagus`), за потреби докачує WebView2 |
| `build.ps1` | `dotnet publish` (self-contained, win-x64) → підпис → Inno Setup → підпис |
| `sign.ps1` | підписує файл, якщо є сертифікат; без нього пропускає |

## Реліз

1. Як завжди, створюєш реліз у GitHub Releases з тегом `vX.Y` і кладеш туди DMG.
2. Після «Publish release» воркфлоу **Windows installer** (`.github/workflows/windows-installer.yml`)
   сам збирає `Potyagus-X.Y-Setup.exe` і додає його в цей самий реліз. Якщо треба перезібрати,
   запусти воркфлоу ще раз: файл перезапишеться.

Без релізу: Actions → Windows installer → Run workflow. Інсталятор `Potyagus-dev-<коміт>-Setup.exe`
буде в артефактах прогону. На PR, що чіпають `windows/`, `web/`, `data/` чи цю папку, він збирається так само.

Локально на Windows (потрібні .NET SDK і `winget install JRSoftware.InnoSetup`):

```powershell
.\installer\windows\build.ps1 -Version 0.4
```

## SmartScreen

Поки інсталятор не підписаний, користувачі бачать:

- у браузері: «Potyagus-…-Setup.exe зазвичай не завантажують» → `…` → «Зберегти» → «Усе одно зберегти»;
- при запуску: «Windows захистила ваш ПК» → «Докладніше» → «Усе одно запустити», видавець «Невідомий видавець».

SmartScreen дивиться на репутацію файлу й підпису. Непідписаний файл набирає репутацію повільно
і з кожною новою версією починає з нуля, тому попередження буде на кожному релізі.

## Підпис (коли захочеться прибрати попередження)

`sign.ps1` уміє підписувати сертифікатом у форматі `.pfx`. Щоб увімкнути, додай у
Settings → Secrets and variables → Actions два секрети: `WINDOWS_CERT_PFX_BASE64`
(вміст `.pfx` у base64) і `WINDOWS_CERT_PASSWORD`. Без них збірка просто лишається непідписаною.

Важливо: з 2023 року нові OV/EV-сертифікати видають лише на апаратних ключах (токен або хмарний HSM),
тому `.pfx`-файл зараз можна отримати хіба що від старого сертифіката. Реальні варіанти:

- **Azure Trusted Signing** (~10 $/міс): найдешевше, репутація накопичується на твоє ім'я, але доступно
  не в усіх країнах для фізосіб, треба перевірити;
- **SignPath Foundation**: безкоштовний підпис для open-source-проєктів;
- **OV/EV-сертифікат** у хмарному HSM (DigiCert KeyLocker, SSL.com eSigner тощо): дорожче, ~200–400 $/рік.

Будь-який з них вимагатиме замінити крок у `sign.ps1` на їхній інструмент. Підпис OV одразу прибирає
«Невідомий видавець», але SmartScreen ще якийсь час може попереджати, поки підпис не набере репутації.
